SESSION 7 - TRAIN YOUR FIRST SMALL MODEL
Additional original practical workshop, beyond the manual's six core classes.
All examples are fictional. No packages, account, API key, or internet needed.

START
Extract the ZIP. Open a terminal in that folder using an existing Python 3 setup.
If Windows uses the launcher, replace python with py in these commands.

1. python session07_train.py
   Starts slope=0, bias=0. Fits 4 training examples with 500 updates at rate0.03.
   Reports training, validation, test, and a training-mean baseline.
2. python session07_train.py --rate 0.001 --steps 500
   Reset happens at the start of each run. Compare validation MAE fairly.
3. python session07_train.py --rate 0.5 --steps 50
   This deliberately oversized rate overshoots. A numerical guard stops training.
4. python session07_train.py --scenario shift
   Test prices change after the training/validation period. Explain the larger error.
5. python session07_train.py --scenario curve
   A straight line cannot exactly represent the curved relationship.

KEEP AND REUSE PARAMETERS
python session07_train.py --output my_model.json
python session07_predict.py my_model.json --hours 3
Or use the example model bundled here:
python session07_predict.py --hours 3
The HTML's "Download model JSON" file can also be passed to session07_predict.py.
Prediction with saved parameters is inference, not another training run.

UNDERSTAND THE SYNTAX
= assigns a value; == compares two values.
* multiplies, + adds, - subtracts, / divides.
+= adds to an accumulator. The HTML's loop explanation also shows -=.
def introduces a function. Parameters receive caller values. return sends a result.
A colon begins a block. Indented lines belong to that block; do not remove spaces.
[] creates a list; () groups a tuple. A (hours, actual) pair keeps input with target.
for reads items repeatedly. range(500) supplies 500 iterations, starting at zero.
len(training) gives the count. abs(error) gives the size without its sign.
An f-string such as f"{value:.6f}" inserts a value with six decimal places.
A dictionary maps names to values. model["slope"] retrieves one named value.
Imports here are built into Python. JSON is saved numeric data, not executable code.
The __name__ guard calls main only when the program is executed directly.

WHY THE TRAINING ORDER MATTERS
Start parameters -> read training pairs -> predict -> compute errors -> accumulate
BOTH gradients from the OLD parameters -> update BOTH parameters -> repeat.
The observed targets do not change. The loop does not read validation/test answers.
Gradient formulas are optional mathematics; trace their arithmetic before deriving.
At zero: dw=-35, db=-12. At rate0.03: new slope1.05, bias0.36.
MSE averages squared errors; MAE averages absolute errors in credits.

SPLITS AND LIMITS
Training inputs: hours1,2,3,4. Validation:5,6. Test:7,8.
Later hours deliberately require extrapolation. These 8 synthetic rows do not
establish realistic performance. In a real project, choose appropriate independent,
representative data and evaluate errors and usefulness.
Use validation to compare choices. Freeze your chosen model before inspecting test.
Once test answers guide another choice, use fresh data for a new independent claim.
The browser permits further exploration after reset and displays this limitation.

ASSIGNMENT
Explain one prediction and the first update. Compare two validation settings.
Freeze a choice; report test MAE and baseline. Explain a changed-data case.
Then design another small numeric task: input, target, baseline, data split, and limit.
Official textbook/ProConnect questions remain separate from these original tasks.
