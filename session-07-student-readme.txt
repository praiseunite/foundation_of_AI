SESSION 7 STUDENT ASSIGNMENT BUNDLE
Original supplementary tasks, not the official textbook question bank.

START
Extract the ZIP. Open session-07-assignments.html in a browser.
Use session-07.html for the interactive lesson and training labs.
The bundle works offline. Seven core tasks need no Python, key, or internet.

WORK AND SUBMIT
Write your own calculations and explanations. Use hints after trying.
The ready checkboxes are self-checks; your teacher awards marks.
The suggested core rubric totals 50 points and about100 minutes of expanded practice.
Your teacher chooses when to assign it, the deadline, and the submission channel.

Use the final Submit page to download a text report and optional JSON draft backup.
Drafts are saved only in the current browser. Export to keep and hand in your work.
The exported draft can be restored later. It replaces the browser's current draft.
Local lab capture requires compatible browser storage between the two pages.
If capture is unavailable, record displayed values manually; the tasks remain usable.

OPTIONAL PYTHON
An existing Python 3 setup can run session07_train.py and session07_predict.py.
session-07-python-guide.txt explains commands and syntax.
session07_tasks_starter.py has clearly labelled TODO steps; it runs with guidance
until you fill the prediction function. Its later training/test steps are optional.
No third-party packages or API calls are used.

Keep test-based improvements honest: after inspecting test answers, subsequent
tuning is exploration. A new independent evaluation needs suitable fresh data.
Tiny fictional examples do not establish real campus price reliability.
